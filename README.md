# Student Performance Data Analysis System

## 📌 Project Overview

The **Student Performance Data Analysis System** is a Python-based
data analysis project developed to analyze and understand student
academic performance.

The system processes student performance data and performs data
loading, exploration, cleaning, preprocessing, performance analysis,
visualization, and report generation.

The project is implemented using **Python, Pandas, NumPy, and
Matplotlib** in **Google Colab**.

---

## 🎯 Objectives

The main objectives of this project are:

- Load and manage student performance data
- Explore the structure and characteristics of the dataset
- Identify missing values and duplicate records
- Detect incorrect and inconsistent data
- Identify possible outliers
- Preprocess the student dataset
- Calculate student average performance
- Analyze and generate grades
- Sort and filter student records
- Identify top-performing students
- Perform department-wise performance analysis
- Visualize student performance using graphs
- Generate a final cleaned dataset and analysis report

---

## 🛠️ Technologies Used

- **Python** – Main programming language
- **Pandas** – Data loading, manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Google Colab** – Development and execution environment

## 📊 Project Modules

### Module 1 – Dataset Loading

Loads the student CSV dataset into Python using Pandas.

Tasks:
- Import libraries
- Upload dataset
- Read CSV file
- Display first and last records
- Check dataset size

### Module 2 – Data Exploration

Explores the structure and characteristics of the dataset.

Tasks:
- Check dataset shape
- Display column names
- Check data types
- Check missing values
- Generate statistical summary
- Display complete dataset information

### Module 3 – Data Cleaning

Checks the quality of the dataset.

Tasks:
- Check missing values
- Check duplicate records
- Check duplicate Student IDs
- Check incorrect age values
- Check incorrect attendance values
- Check incorrect examination scores
- Remove duplicate records

### Module 4 – Data Preprocessing

Prepares the data for further analysis.

Tasks:
- Prepare numerical data
- Detect possible outliers
- Use IQR-based outlier detection
- Create the Average column
- Verify the processed dataset

### Module 5 – Performance Analysis

Analyzes student academic performance.

Tasks:
- Calculate student average
- Analyze grades
- Sort student records
- Filter high-performing students
- Identify the topper
- Perform department-wise analysis
- Calculate overall performance

### Module 6 – Data Visualization

Visualizes the analysis results using Matplotlib.

Visualizations include:

- Grade Distribution Bar Graph
- Grade Distribution Pie Chart
- Box Plot for Outlier Detection
- Midterm vs Final Performance Comparison
- Department-wise Average Performance
- Top 10 Student Performance

### Module 7 – Report Generation

Generates the final project outputs.

Outputs include:

- Dataset summary
- Cleaned dataset
- Student statistics
- Topper information
- Grade distribution
- Department-wise analysis
- Performance insights
- Final analysis report
